# Body-Performance

# Información sobre el DataFrame:

## Tamaño 
#### (13388, 12)
## Columnas
| Variable | Descripción / Significado | Valores / Formato |
| :--- | :--- | :--- |
| **age** | Age of the individual | 20 ~ 64 |
| **gender** | Biological sex | F, M |
| **height_cm** | Height in centimeters *(Divide by 30.48 to convert to feet)* | Numeric |
| **weight_kg** | Weight in kilograms | Numeric |
| **body fat_%** | Body fat percentage | Numeric (%) |
| **diastolic** | Diastolic blood pressure (min) | Numeric (mmHg) |
| **systolic** | Systolic blood pressure (min) | Numeric (mmHg) |
| **gripForce** | Hand grip strength measurement | Numeric |
| **sit and bend forward_cm** | Flexibility test measurement | Numeric (cm) |
| **sit-ups counts** | Abdominal endurance test score | Numeric (count) |
| **broad jump_cm** | Explosive leg power test distance | Numeric (cm) |
| **class** | Physical fitness level classification | A, B, C, D *(A: best)* |
## Variable objetivo
#### **class**: Grade of body performance
